# GFX TOOL PRO

### Advanced GFX Explorer & Image Editor for Hearts of Iron IV Modding

---

# 🇷🇺 РУССКИЙ (RU)

## Описание

GFX TOOL PRO — современный инструмент для моддеров Hearts of Iron IV, предназначенный для удобной работы с GFX-файлами, изображениями и структурой сабмодов.

Программа автоматически анализирует содержимое оригинального мода и вашего сабмода, позволяет быстро находить изображения, заменять их, просматривать различия и редактировать графику прямо внутри программы.

---

## Основные возможности

* 🔍 GFX Explorer с поиском по файлам и папкам
* ⚡ Быстрое сравнение оригинального мода и сабмода
* 🖼️ Просмотр оригинального изображения и версии сабмода
* ✏️ Встроенный редактор изображений
* 📐 Автоматическое определение размера оригинального GFX
* 🎯 Готовые пресеты Hearts of Iron IV:

  * Leader Portrait
  * Event Picture
  * National Focus
  * Idea / Minister
* 🧩 Режимы масштабирования:

  * Fit
  * Fill
  * Stretch
* 🌙 Светлая и тёмная тема
* 🌍 Мультиязычный интерфейс
* 📂 Автоматическое сохранение структуры папок

---

## Инструкция

1. Запустите `GFX_TOOL.exe`
2. Выберите папку оригинального мода
3. Выберите папку сабмода
4. Нажмите `Начать анализ GFX`
5. Найдите нужный файл через проводник или поиск
6. Выберите изображение из списка
7. Нажмите `START: Заменить / Добавить`
8. Выберите новое изображение
9. При необходимости отредактируйте его во встроенном редакторе
10. Нажмите `Применить и Сохранить`

Программа автоматически создаст нужные папки и заменит файл с сохранением структуры мода.

---

## Системные требования

* Windows 10 / 11

# 🇬🇧 ENGLISH (EN)

## Description

GFX TOOL PRO is an advanced utility for Hearts of Iron IV modders designed for fast and convenient GFX management.

The application compares original mod assets with your submod, allows instant file replacement, image previewing, and built-in image editing while preserving the correct folder structure automatically.

---

## Main Features

* 🔍 GFX Explorer with search system
* ⚡ Fast comparison between original mod and submod
* 🖼️ Original/Submod image preview
* ✏️ Built-in image editor
* 📐 Automatic original image size detection
* 🎯 HOI4 presets:

  * Leader Portrait
  * Event Picture
  * National Focus
  * Idea / Minister
* 🧩 Scaling modes:

  * Fit
  * Fill
  * Stretch
* 🌙 Dark & Light themes
* 🌍 Multi-language interface
* 📂 Automatic folder structure preservation

---

## Instructions

1. Run `GFX_TOOL.exe`
2. Select the Original Mod folder
3. Select the Submod folder
4. Click `Start GFX Analysis`
5. Find the target file using Explorer/Search
6. Select the image
7. Click `START: Replace / Add`
8. Choose a new image
9. Edit it if needed using the built-in editor
10. Click `Apply & Save`

The program will automatically copy and replace the file while keeping the correct mod structure.
